# Advent of Code 2025 - Soluciones en C++

Este repositorio contiene mis soluciones para el [Advent of Code](https://adventofcode.com/), implementadas principalmente en **C++** con un enfoque en eficiencia y gestión de memoria manual.

**Nota:** El objetivo de este proyecto es resolver los puzzles algorítmicos diarios manteniendo un código limpio y modular, organizado por carpetas.

## Estructura del Proyecto

El repositorio sigue una arquitectura modular donde cada día es independiente, pero comparte utilidades comunes si es necesario.

```
.
├── Dia-01/          # Historian Hysteria
├── Dia-05/          # Print Queue
├── Dia-07/          # Bridge Repair
├── Dia-08/          # Resonant Collinearity
├── Dia-11/          # Plutonian Pebbles
├── Makefile
└── README.md        # Documentación principal

```

### Instrucciones de ejecución

Las instrucciones de ejecución se encuentran las de cada uno de los días al final de la memoria de cada uno de ellos.
